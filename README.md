# Console redesign mockups

Static design mockups for the `faucet serve` web console redesign. Sample data only; not product code.

Open `console-redesign/index.html` in a browser (from a local checkout; GitHub shows HTML as source) and pick the screen and theme in the URL:

- `?view=runs|templates|changes|datasets`
- `&theme=light` or `&theme=teal` (dark is the default)

For example `console-redesign/index.html?view=runs&theme=teal`.

The `teal` theme is the light theme with teal-tinted surfaces, lines and text, a teal accent on the selected item, and a soft teal gradient behind the shell. Screenshots of every view in each theme are in `console-redesign/<view>-<dark|light|teal>.png`.
