# Console redesign mockups

Static design mockups for the `faucet serve` web console redesign. Sample data only; not product code.

Open `console-redesign/index.html` in a browser (from a local checkout; GitHub shows HTML as source) and pick the screen and theme in the URL:

- `?view=runs|templates|changes|datasets`
- `&theme=light` (dark is the default)

For example `console-redesign/index.html?view=runs&theme=light`.

Both themes use teal only to highlight: the active nav item, the selected row, active tabs and the `stable` channel chip. Screenshots of every view in both themes are in `console-redesign/<view>-<dark|light>.png`.

`console-redesign/deprecated/` keeps the earlier light and dark version, without the teal highlights, for reference.
