# Console redesign mockups

Static design mockups for the `faucet serve` web console redesign. Sample data only; not product code.

Open `console-redesign/index.html` in a browser (from a local checkout; GitHub shows HTML as source) and pick the screen and theme in the URL:

- `?view=runs|templates|changes|datasets`
- `&theme=light`, `&theme=teal` or `&theme=teal-dark` (dark is the default)

For example `console-redesign/index.html?view=runs&theme=teal`.

The `teal` theme is the light theme with teal used only to highlight: the active nav item, the selected row, active tabs and the `stable` channel chip. `teal-dark` is the dark theme with the same teal highlights. Screenshots of every view in each theme are in `console-redesign/<view>-<dark|light|teal|teal-dark>.png`.
